{% comment %} Salinan dari unfold/templates/admin/nav_sidebar.html, dengan satu perubahan: membuat buka/tutup sidebar beranimasi. Aslinya memakai x-show="sidebarOpen". Direktif x-show milik Alpine hanya menyetel display:none, jadi sidebar lenyap seketika dan area konten melompat melebar tanpa transisi. Di sini x-show diganti kelas 'av-sidebar--closed'; lebar dan geserannya dianimasikan lewat CSS di static/css/unfold_override.css. Catatan: sidebarOpen di unfold/js/app.js dideklarasikan sebagai METHOD, lalu diganti menjadi boolean oleh sidebarToggle(). Alpine memanggil method itu bila ekspresinya berdiri sendiri (seperti x-show), tetapi TIDAK bila dipakai di tengah ekspresi lain - karenanya pemeriksaan typeof di bawah. Tanpa itu, saat halaman dimuat pertama kali sidebar selalu dianggap terbuka meski pengguna terakhir menutupnya. Isi menu tetap diambil dari template Unfold (unfold/helpers/navigation.html), jadi yang "dibekukan" di sini hanya kerangka pembungkusnya. {% endcomment %} {% load i18n unfold %}
